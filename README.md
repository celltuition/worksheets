# Cell Tuition worksheets

The worksheet pages, PDFs and index for celltuition.com/worksheets. Built by `tools/publish.ps1` in the private
Cell Tuition Worksheets project; nothing here is edited by hand.

- `page.html?sheet=<name>` is a worksheet page, `sheets/<name>.html` the worksheet itself (questions only), `pdf/<name>.pdf` its PDF.
- `index.json` lists every sheet (title, years, strand, sections) for the library page on celltuition.com.
